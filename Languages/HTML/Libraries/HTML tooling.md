## You rarely write raw HTML

In this stack, HTML is **generated**:

| Generated by | Note |
|---|---|
| **React / JSX** | [[NextJs TypeScript]] · [[TSX]] |
| **Django templates** | [[Django]] |
| **Streamlit** | [[Streamlit]] — writes it all for you |
| Jinja2 | Python templating, used by FastAPI when serving pages |

## Templating

```jinja
{# Jinja2 / Django #}
{% extends "base.html" %}
{% block content %}
  <h1>{{ title }}</h1>
  {% for item in items %}
    <li>{{ item.name }}</li>
  {% else %}
    <li>Nothing here.</li>
  {% endfor %}
{% endblock %}
```

> **`{{ }}` auto-escapes by default in Jinja2 and Django** — that's what stops user input becoming an XSS hole. Only disable it (`|safe`) when you are certain the content is trusted ([[26 — SECURITY]]).

## Parsing HTML (scraping)

```python
from bs4 import BeautifulSoup                 # uv add beautifulsoup4 lxml

soup = BeautifulSoup(html, "lxml")
soup.find("h1").text
soup.find_all("a", class_="product")
soup.select("div.card > a[href]")             # CSS selectors
[a["href"] for a in soup.select("a[href]")]
```

```python
import lxml.html                              # faster for big documents
tree = lxml.html.fromstring(html)
tree.xpath("//div[@class='card']/a/@href")
```

Used in [[B2B webscraping tool]].
