Common types:

|Type|Meaning|
|---|---|
|i32|Integer|
|i64|Large integer|
|u32|Unsigned integer|
|f32|Float|
|f64|Double precision float|
|bool|True/False|
|char|Single character|

defining types in rust

```rust
let age: i32 = 25;
let pi: f64 = 3.14;
let active: bool = true;
let grade: char = 'A';
```
