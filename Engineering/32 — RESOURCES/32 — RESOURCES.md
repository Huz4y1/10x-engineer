## Mathematics
- 3Blue1Brown — *Essence of Linear Algebra* / *Essence of Calculus* (YouTube). The best intuition anywhere.
- Mathematics for Machine Learning (Deisenroth, Faisal, Ong) — free PDF

## Programming
- *Pro Git* (free) · [The Rust Book](https://doc.rust-lang.org/book/) · C++ Core Guidelines

## Computer science
- *Computer Systems: A Programmer's Perspective*
- *Designing Data-Intensive Applications* (Kleppmann) — **the** distributed systems book

## ML / DL
- fast.ai — *Practical Deep Learning*
- Karpathy — *Neural Networks: Zero to Hero* — build a GPT from scratch
- *Deep Learning* (Goodfellow) — the reference
- [Karpathy: A Recipe for Training Neural Networks](https://karpathy.github.io/2019/04/25/recipe/)

## ML engineering

## Data engineering
