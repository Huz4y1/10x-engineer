# Django Assessment Centre - Project Architecture

Features include:

- Authentication
- Note-taking
- Application assessment packs
- REST API
- Admin dashboard

Complete Request Flow

User Registration

1. User visits /signup/
2. URL router sends request to SignUpView
3. SignUpView displays:
    - username field
    - password field
    - confirm password field
4. User submits form
5. Validation checks:
    - passwords match
    - username is unique
    - custom validators pass
6. User is saved to database
7. User redirected to login page

Login Process

1. User visits /login/
2. User enters credentials
3. Django checks:
    - user exists
    - password hash matches
4. Session is created
5. Session cookie stored in browser
6. User redirected to home page

Rule of Thumb:

Views should be thin.

Services should be fat.

Views:

- Receive request
- Return response

Services:

- Business logic
- Validation
- Calculations
- Database operations
- External API calls

Models:

- Represent database tables
- Query database

Templates:

- Render HTML
